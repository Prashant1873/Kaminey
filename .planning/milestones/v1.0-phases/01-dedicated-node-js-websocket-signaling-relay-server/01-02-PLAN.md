  <action>
In `server/server.js`:
1. Implement handling for `action: 'RELAY'`:
   - Message shape: `{ action: 'RELAY', roomCode, senderId, targetId, payload, timestamp }`
   - If `targetId === 'host'`: forward payload to room's `hostSocket` as `{ type: 'RELAY_MESSAGE', senderId, payload, timestamp }`.
   - If `targetId === 'all'`: broadcast to all active player sockets in the room and host socket (excluding sender).
   - If `targetId === playerId`: forward directly to `room.players.get(playerId).socket`.
2. Implement heartbeat and dead-room cleanup interval (every 30s):
   - Ping connected sockets via `ws.ping()`. If pong is not received within 10s, mark socket as terminated.
   - If a room has no host connected and no players for >60s, delete the room from `rooms` map and log cleanup.
  </action>
  <verify>grep -n "action === 'RELAY'" server/server.js</verify>
  <acceptance_criteria>
    - `server/server.js` contains `action === 'RELAY'` handler
    - `server/server.js` supports unicast and broadcast forwarding
    - `server/server.js` has dead room cleanup logic
  </acceptance_criteria>
  <done>Fallback relaying and garbage collection operational</done>

  <files>src/network/hybridBridge.js</files>
  <read_first>src/network/hybridBridge.js</read_first>
  <action>
In `src/network/hybridBridge.js`:
1. In constructor, attach browser lifecycle listeners if `typeof window !== 'undefined'`:
   - `document.addEventListener('visibilitychange', this.handleVisibilityChange)`
   - `window.addEventListener('online', this.handleOnline)`
2. In `handleVisibilityChange()`:
   - If `document.visibilityState === 'visible'`:
     - Check if `this.ws` is dead (`!this.ws || this.ws.readyState !== WebSocket.OPEN`).
     - If dead, trigger `this.init()` immediately.
     - If socket is open, immediately dispatch `{ type: 'REQUEST_STATE_SYNC', playerId: this.id }` to host.
3. In `handleOnline()`:
   - If socket is disconnected, trigger `this.init()`.
4. Clean up event listeners in `destroy()`.
  </action>
  <verify>grep -n "visibilitychange" src/network/hybridBridge.js</verify>
  <acceptance_criteria>
    - `src/network/hybridBridge.js` attaches `visibilitychange` listener
    - Triggers reconnection and sends `REQUEST_STATE_SYNC` upon wake
    - Cleans up listeners in `destroy()`
  </acceptance_criteria>
  <done>Lifecycle listeners and screen wake resync added to HybridNetworkBridge</done>
</task>

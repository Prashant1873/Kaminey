# Plan 07-01: Apple Fluid Spring Animation Utility & Engine

## Objective
Implement physics-based Apple fluid springs engine in `src/styles/springs.js` and supporting CSS transition classes in `src/index.css`.

## Scope
1. Implement `src/styles/springs.js`:
   - `springSettle()`: Critically damped interface settling (`damping: 1.0`, zero bounce, `duration: 350ms`), fully interruptible and cancelable mid-flight using Web Animations API (WAAPI).
   - `springMomentum()`: Underdamped momentum fling (`damping: 0.8`, `bounce: 0.15`, velocity handoff).
   - `useSpringPhysics()`: React hook for fluid card gestures, dragging, and reveal interactions.
2. Add Apple fluid spring keyframes and utility classes in `src/index.css`:
   - `.spring-settle-in`: Apple fluid spring entrance (transform scale 0.94 -> 1, opacity 0 -> 1 with cubic-bezier(0.16, 1, 0.3, 1)).
   - `.spring-flick-release`: Tactile swipe release momentum.
   - `.spring-card-settle`: Card flip / reveal motion with zero overshoot.
3. Verify WAAPI compatibility and test compilation.

## Success Criteria
- `src/styles/springs.js` exports reusable spring engine and hook.
- CSS classes defined and available.
- Zero syntax or build errors.

# Plan 06-01: Build Tactile Control Primitives

## Objective
Build production tactile control primitives in `src/components/common/` (`Button.jsx`, `Toggle.jsx`, `SegmentedControl.jsx`) enforcing sub-pixel optical centering, concentric radii formulas, and viscoelastic kinetics.

## Scope
1. Implement `Button.jsx`:
   - Variants: `primary`, `secondary`, `danger`, `ghost`
   - Sub-pixel optical centering: SVG icons offset by `translateY(-0.5px)` relative to cap-height
   - Instant active tactile feedback (`:active` scale(0.98), damping 1.0)
   - Minimum 44x44px touch target compliance (Fitts's Law)
2. Implement `Toggle.jsx`:
   - Viscoelastic thumb stretch-and-squish kinetics during transition
   - Accessible keyboard toggle with ARIA attributes
3. Implement `SegmentedControl.jsx`:
   - Viscoelastic sliding indicator with width expansion during drag/click
   - Concentric nested corner radius: $r_{inner} = r_{outer} - padding$
4. Add supporting CSS rules in `src/index.css`.

## Success Criteria
- Button, Toggle, and SegmentedControl components export cleanly.
- Concentric corner radii and optical centering enforced.
- Build compiles without syntax errors.

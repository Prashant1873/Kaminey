# Plan 08-01: Coordinated Skeleton Primitives & Atomic Synchronization Engine

## Objective
Build atomic skeleton primitives in `src/components/common/Skeleton.jsx` and an atomic synchronization barrier in `src/components/common/AtomicLoadingBarrier.jsx` preventing staggered element pop-in.

## Scope
1. Implement `Skeleton.jsx`:
   - Primitives: `SkeletonBox`, `SkeletonText`, `SkeletonAvatar`, `SkeletonCard`
   - Shimmer animation with Haveli amber undertone glow
   - Exact dimension mirroring (aspect ratio & padding match final UI)
2. Implement `AtomicLoadingBarrier.jsx`:
   - Coordinates readiness across child subsystems or phase switch
   - Holds presentation in a synchronized skeleton layout until all resources/elements are ready
   - Performs a single 60fps atomic crossfade reveal (zero CLS layout shift)
3. Add supporting CSS in `src/index.css`.

## Success Criteria
- Skeleton primitives match target layouts with zero layout shifts.
- Atomic barrier reveals complete views in a single frame.
- Vite build compiles cleanly.

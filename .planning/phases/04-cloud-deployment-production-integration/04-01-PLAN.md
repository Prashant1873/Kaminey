<task type="auto">
  <name>Task 2: Update client endpoint resolution for GitHub Pages production fallback</name>
  <files>src/network/config.js</files>
  <read_first>src/network/config.js</read_first>
  <action>
In `src/network/config.js`:
1. Define `export const DEFAULT_PRODUCTION_WS_URL = 'wss://kaminey-server.onrender.com';` (or configurable cloud relay).
2. In `getWebSocketServerUrl()`:
   - Check `import.meta.env?.VITE_WS_SERVER_URL`: if present, return it.
   - If in browser and `hostname` is local (`localhost`, `127.0.0.1`, LAN IPs `192.168.`, `10.`, `.local`), return `ws://${hostname}:3001`.
   - If `hostname.includes('github.io')` or other deployed domain without port 3001 support:
     return `DEFAULT_PRODUCTION_WS_URL`.
   - Otherwise, fall back to secure protocol `${wsProto}//${hostname}:3001`.
  </action>
  <verify>npm run build</verify>
  <acceptance_criteria>
    - `src/network/config.js` falls back to `DEFAULT_PRODUCTION_WS_URL` when on `github.io`
    - `npm run build` succeeds cleanly
  </acceptance_criteria>
  <done>Endpoint resolution updated with production fallback</done>
</task>

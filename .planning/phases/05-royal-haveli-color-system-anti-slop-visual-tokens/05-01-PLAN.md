# Plan 05-01: Token Definitions & Color Scale Architecture

## Objective
Establish the anti-slop Royal Haveli design tokens, palette definitions, and WCAG 2.2 AA semantic tokens in `src/styles/tokens.css` and integrate with `src/index.css`.

## Scope
1. Create `src/styles/tokens.css` with:
   - Primary: Imperial Warm Gold (`#E5B869` / `#D4A34E`)
   - Secondary: Palace Crimson / Terracotta (`#9E2A2B` / `#B83A3B`)
   - Accent Emerald: Peacock Jade (`#10B981` / `#0D9488`)
   - Warm Neutral: Haveli Sandstone (`#E8DFD0` / `#D4C7B5`)
   - Surfaces: Tinted Midnight Onyx (`#090A0F`, `#0F1118`, `#161924`, `#1D2230`) with amber/gold warmth
   - WCAG 2.2 AA contrast verified values (min 4.5:1 text, 3:1 interactive/icons)
   - Zero generic AI-purple meshes or untinted pure gray-on-black slop
2. Import `tokens.css` into `src/index.css` and map root tokens cleanly to `--color-*` and theme variables.
3. Validate token availability and verify build.

## Success Criteria
- Tokens file exists and exports comprehensive palette and semantic design tokens.
- Light and dark themes provide strict WCAG 2.2 AA contrast standards.
- Production build succeeds without errors.
